The Science of Digital Images

1. What is a Pixel?

The word Pixel stands for "Picture Element." It is the smallest unit of a digital image. In a simple black and white image, one bit of memory (a 0 or a 1) represents exactly one pixel.

2. How Mapping Works

Computers read a long string of binary code and "map" it onto a grid. In our 8x8 grid above, the computer needs 64 bits to draw the image. It starts at the top-left and moves row by row, just like reading a book.

  • 0 = Lamp is OFF (White Pixel)
  • 1 = Lamp is ON (Black Pixel)

3. From Binary to Pictures

When you draw a "smiley face" on the grid, you are actually creating a Bitmap. A bitmap is a map of bits that tells the screen which tiny lights to turn on. High-definition photos use millions of pixels and many bits per pixel to show colors, but the basic logic is exactly the same!
