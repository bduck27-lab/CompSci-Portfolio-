How Computers Display Color

1. The RGB Model

Unlike paint (where mixing colors gets darker), computer screens use Additive Color. By mixing Red, Green, and Blue light at different intensities, a screen can create over 16 million different colors!

2. Indexed Color (The Snake Method)

In the snake image above, the computer uses a "Palette." Instead of storing a complex color for every pixel, it stores a simple number. The computer looks at a table to see that a specific code means a specific shade. This makes images much smaller and faster to load.

3. Bits Per Pixel

While black and white images only need 1 bit per pixel, color images need much more. A standard high-quality image uses 24 bits for every single pixel—8 bits for Red, 8 for Green, and 8 for Blue.
